Lightweight projection of the full events endpoint — returns only `name`, `coords`, `date_start`, `date_end` and `recurring`. Designed for rendering event pins on a map without the overhead of descriptions and full metadata.

Accepts the same query parameters and headers as [`/pois/events`](/docs/poi-api/events), including the BYOK headers `X-Ticketmaster-Key` and `X-Eventbrite-Token`.

<Callout type="info">
  The minimum search radius is **50 km**, enforced server-side.
</Callout>

---

## Request headers

| Header | Required | Description |
|--------|:--------:|-------------|
| `X-API-Key` | yes | Your API key |
| `X-Ticketmaster-Key` | no | Your Ticketmaster Discovery API key |
| `X-Eventbrite-Token` | no | Your Eventbrite private token |

---

## Query parameters

| Name | Type | Required | Default | Description |
|------|------|:--------:|---------|-------------|
| `mode` | string | — | `radius` | `radius` · `district` |
| `lat` | float | radius | — | Latitude WGS-84 |
| `lng` | float | radius | — | Longitude WGS-84 |
| `radius` | int | no | `50000` | Search radius in metres (minimum 50 000) |
| `district` | string | district | — | District or city name |
| `lang` | string | no | `en` | ISO 639-1 language code |
| `limit` | int | no | `20` | Max results (max 100) |
| `offset` | int | no | `0` | Pagination offset |

### `SlimEvent` fields

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Event name |
| `coords` | object | `lat`, `lng`, `approximate` |
| `date_start` | string | ISO 8601 start datetime, omitted if unknown |
| `date_end` | string | ISO 8601 end datetime, omitted if unknown |
| `recurring` | bool | `true` for annually recurring events |
