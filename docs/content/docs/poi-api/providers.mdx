Lists all data providers registered on this instance and probes each one for availability and latency. No authentication required.

<Callout type="info">
  **Ticketmaster** and **Eventbrite** always appear as available — they use BYOK (Bring Your Own Key) and require no server-side credentials. Their probe returns immediately without making an external HTTP call.
</Callout>

---

## Response `200`

```json
[
  { "name": "overpass",           "available": true,  "latency_ms": 145 },
  { "name": "wikivoyage",         "available": true,  "latency_ms": 312 },
  { "name": "wikipedia",          "available": true,  "latency_ms": 203 },
  { "name": "wikipedia_events",   "available": true,  "latency_ms": 890 },
  { "name": "geonames",           "available": true,  "latency_ms": 89  },
  { "name": "ticketmaster",       "available": true,  "latency_ms": 0   },
  { "name": "eventbrite",         "available": true,  "latency_ms": 0   }
]
```

### `ProviderStatus` fields

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Provider identifier |
| `available` | bool | `true` if the probe returned without error |
| `latency_ms` | int | Round-trip time in milliseconds (`0` for BYOK providers) |
| `error` | string | Error message when `available` is `false` |

### Provider identifiers

| Name | Source | Notes |
|---|---|---|
| `overpass` | OpenStreetMap / Overpass API | Always active |
| `wikivoyage` | Wikivoyage MediaWiki API | Always active |
| `wikipedia` | Wikipedia geosearch | Always active |
| `wikipedia_events` | Wikipedia + Wikidata SPARQL | Always active — festivals only |
| `geonames` | GeoNames API | Active only when `POI_GEONAMES_USERNAME` is set |
| `ticketmaster` | Ticketmaster Discovery API v2 | BYOK — supply `X-Ticketmaster-Key` per request |
| `eventbrite` | Eventbrite API v3 | BYOK — supply `X-Eventbrite-Token` per request |
