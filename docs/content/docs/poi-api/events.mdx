Returns cultural events and festivals near the given location. Always queries **Wikipedia/Wikidata** (recurring festivals classified under Wikidata class Q132241). Optionally activates **Ticketmaster** and **Eventbrite** when you supply your own API keys in request headers — the server stores nothing.

Results from all active providers are merged, deduplicated, and sorted by relevance score. Events at the same venue on different dates are never merged.

<Callout type="info">
  The minimum search radius is **50 km**, enforced server-side. Paid event APIs (Ticketmaster, Eventbrite) return few or no results at smaller radii.
</Callout>

---

## Request headers

| Header | Required | Description |
|--------|:--------:|-------------|
| `X-API-Key` | yes | Your API key |
| `X-Ticketmaster-Key` | no | Your Ticketmaster Discovery API key — activates TM results |
| `X-Eventbrite-Token` | no | Your Eventbrite private token — activates EB results |

<Callout type="warn">
  BYOK keys are used for a single HTTP round-trip and **never** logged, cached as key material, or stored server-side. The cache key encodes only which providers were active (not the key values themselves).
</Callout>

## Query parameters

| Name | Type | Required | Default | Description |
|------|------|:--------:|---------|-------------|
| `mode` | string | — | `radius` | `radius` · `district` |
| `lat` | float | radius | — | Latitude WGS-84 |
| `lng` | float | radius | — | Longitude WGS-84 |
| `radius` | int | no | `50000` | Search radius in metres (minimum 50 000) |
| `district` | string | district | — | District or city name |
| `lang` | string | no | `en` | ISO 639-1 language code |
| `limit` | int | no | `20` | Max results (max 100) |
| `offset` | int | no | `0` | Pagination offset |

## Response `200`

Same shape as `/pois/search` — a `SearchResult` object with `query`, `total`, and `results`.

```json
{
  "query": { "mode": "radius", "lat": 48.8566, "lng": 2.3522, "radius": 50000 },
  "total": 5,
  "results": [
    {
      "id":          "wikipedia:3276325",
      "name":        "Fête de la Musique",
      "type":        "event",
      "score":       82.0,
      "coords":      { "lat": 48.8566, "lng": 2.3522, "approximate": false },
      "description": "Annual free music festival held on 21 June throughout France.",
      "sources":     ["wikipedia_events"],
      "recurring":   true
    },
    {
      "id":          "ticketmaster:Z698xZC2Z17avvF",
      "name":        "Coldplay – Music of the Spheres",
      "type":        "event",
      "score":       61.0,
      "coords":      { "lat": 48.9244, "lng": 2.3601, "approximate": false },
      "contact":     { "website": "https://www.ticketmaster.fr/…" },
      "sources":     ["ticketmaster"],
      "date_start":  "2025-07-12T19:30:00Z",
      "date_end":    "2025-07-12T23:00:00Z",
      "recurring":   false
    }
  ]
}
```

### Event-specific fields

| Field | Type | Description |
|-------|------|-------------|
| `recurring` | bool | `true` for annually recurring festivals (Wikipedia source) |
| `date_start` | string | ISO 8601 start datetime when available |
| `date_end` | string | ISO 8601 end datetime when available |

---

## Data sources

| Provider | Always active | Requires header | Coverage |
|---|:---:|:---:|---|
| Wikipedia / Wikidata | yes | — | Recurring cultural festivals (music, film, food, carnival…) |
| Ticketmaster | no | `X-Ticketmaster-Key` | Ticketed concerts, sports, theatre |
| Eventbrite | no | `X-Eventbrite-Token` | Community events, classes, conferences |

---

## Error responses

| Status | Condition |
|--------|-----------|
| `400` | Missing required parameters or unsupported mode (`polygon` not supported) |
| `429` | Rate limit exceeded |
| `500` | Internal error |
